## AtomGit AI Notebook Lab

The notebooks in this directory were developed on the
[AtomGit AI Notebook Lab](https://docs.gitcode.com/docs/help/home/ai-community/ai-notebook/)
cloud environment with a single training-optimized Ascend 910B4 NPU chip and
core.

The software versions used are listed in the table below.

| OS version | Python version | MindSpore version | CANN version |
| --- | --- | --- | --- |
| Ubuntu 22.04 LTS | `3.11` | `2.8.0` | `8.5.0` |
